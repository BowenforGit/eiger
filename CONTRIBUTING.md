# Contributing

## Introduction

Except for the tests and benchmarks, all `.cu` and `.cpp` files are compiled independently and linked into the `libgamax.so` dynamic library. Therefore, you need to add the new `.cu/cpp` files into the `CMakeLists.txt`. Currently, all source files are added to `src/CMakeLists.txt`.
